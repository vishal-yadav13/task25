# FlowApp SaaS Landing Page

## Project Overview

FlowApp is a responsive SaaS landing page built using **HTML** and **Tailwind CSS (CDN)**. The project demonstrates modern UI design with animations, glassmorphism, gradient backgrounds, and responsive layouts.

## Features

* Responsive Navigation Bar
* Hero Section
* Floating Orbs
* Morphing Blob Animation
* Rotating Ring Animation
* Grid Background
* 3D Dashboard Preview
* Scroll Indicator
* Bento Grid Features Section
* AI Automation Card
* Speed Card
* Security Card
* Analytics Card
* Smart Sync Card
* Team Collaboration Card
* Testimonials Section
* Glassmorphism Cards
* Star Ratings
* Animated CTA Section
* Footer
* Custom Tailwind Animations

## Technologies Used

* HTML5
* Tailwind CSS (CDN)

## How to Run

1. Download or extract the project folder.
2. Open the folder in Visual Studio Code.
3. Install the **Live Server** extension (if not already installed).
4. Right-click on **index.html**.
5. Select **Open with Live Server**.
6. The website will open in your browser.
